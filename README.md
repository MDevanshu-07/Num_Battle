# Math Quiz Game 🧮

A Python-based math quiz game with difficulty levels and performance visualization.

# Features
- Easy / Medium / Hard modes
- Randomized Math questions
- Score tracking
- Performance graph using Matplotlib

# Requirements
- Python 3.10+
- NumPy
- Matplotlib

# Clone the repository
git clone <your-repo-url>
cd <repo-name>

# Install dependencies
pip install -r requirements.txt

# Run the program
python main.py
